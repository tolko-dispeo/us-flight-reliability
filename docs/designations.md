Обозначения.

DAY_OF_WEEK - день недели

FL_DATE - дата рейса
OP_UNIQUE_CARRIER - код авиакомпании (не уникален во времени)
OP_CARRIERну у _AIRLINE_ID - постоянный ID авиакомпании DOT (даже если компания ликвидируется код остается за ней)
TAIL_NUM - бортовой номер самолёта (Уникален для конкретного физического самолета)
OP_CARRIER_FL_NUM - номер рейса (Код конкретного маршрута в расписании авиакомпании)

ORIGIN_AIRPORT_ID - постоянный DOT ID аэропорта вылета (постоянный во времени, привязан к географии аэропорта)
ORIGIN_AIRPORT_SEQ_ID - версия аэропорта в конкретный момент времени (id + версия) 
ORIGIN - код аэропорта (непостоянный во времени)
ORIGIN_CITY_NAME - город аэропорта вылета
ORIGIN_STATE_ABR - код штата, откуда вылетают

DEST_AIRPORT_ID - постоянный DOT ID аэропорта назначения
DEST_AIRPORT_SEQ_ID - версия аэропорта в конкретный момент времени (id + версия) 
DEST - код аэропорта назначения (непостоянный во времени)
DEST_CITY_NAME - город назначения 
DEST_STATE_ABR - штат назначения 

CRS_DEP_TIME - запланированное время вылета
DEP_TIME - фактическое время вылета
DEP_DELAY - задержка вылета в минутах
TAXI_OUT - время руления от гейта до взлёта

TAXI_IN - время от посадки до гейта
CRS_ARR_TIME - плановое время прилёта
ARR_TIME - фактическое время прилёта
ARR_DELAY - задержка прилёта в минутах

CANCELLED - был ли рейс отменён (1, если да. Иначе 0)
CANCELLATION_CODE - код причины отмены
DIVERTED - был ли рейс перенаправлен (1, если да. Иначе 0)
AIR_TIME - время непосредственно в воздухе, минуты
DISTANCE - расстояние между аэропортами, мили

CARRIER_DELAY - задержка по причинам авиакомпании
WEATHER_DELAY - погодная задержка
NAS_DELAY - задержка National Air System
SECURITY_DELAY - задержка из-за безопасности
LATE_AIRCRAFT_DELAY - задержка из-за позднего прибытия предыдущего рейса этого самолёта
